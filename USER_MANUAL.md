# SIMS User Manual

## 1. Overview

SIMS (Smart Inventory Management System) is the web-based system used to manage faculty inventories, request items, track transfers and disposals, and review approvals.

The system is organized around a left-side navigation menu. The options you see depend on your role.

## 2. Getting started

### Sign in

1. Open the application in your browser.
2. On the login page, enter your email address and password.
3. Click Sign In.
4. After login, you will be taken to your role-based dashboard.

### Create an account

If you do not already have an account, use the Sign Up page to submit a staff account request. The request is sent for review by your Department Head before activation.

### Forgot password

Use the Forgot Password link on the login page to reset your password.

## 3. Roles and permissions

The system supports the following main user roles:

- Admin: manages users, departments, inventories, and reports.
- Registrar: reviews and approves inventory-related requests such as inventory creation, transfers, and disposals.
- Inventory Officer / In-charge: manages inventory items, transfers, disposals, repairs, warranty claims, and reports.
- Head of Department (HOD): reviews staff requests and department-related approvals.
- Dean: reviews higher-level approvals and faculty-wide inventory information.
- Staff Member: requests items, tracks personal requests, and views issued items.

## 4. Main screens

### Dashboard

Each role has a dashboard that shows:

- quick summary cards,
- recent activity,
- pending tasks, and
- shortcuts to common actions.

### Inventory

Use the Inventory section to:

- view all items,
- search or filter items,
- add new items,
- open an item detail page,
- review item status and location.

### Requests

Use Requests to:

- submit an item request,
- view the status of your requests,
- review requests assigned to you for approval,
- track issued items.

### Transfers

Use Transfers to:

- create a transfer request,
- select source and destination inventories,
- track the approval workflow,
- view transfer details and generated documents.

### Disposals

Use Disposals to:

- submit a disposal request,
- enter the reason and condition of the item,
- track disposal approval status,
- review disposal details and reports.

### Repairs and warranty claims

Use Repairs and Warranty Claims to:

- record repairs,
- submit warranty-related claims,
- track their status.

### Administration

Admins can use the Admin section to:

- manage users,
- create or edit departments,
- manage inventories,
- review reports,
- view system activity.

## 5. Common user workflows

### A. Requesting an item

1. Open the navigation menu and go to Request Items.
2. Select the requested inventory location.
3. Enter the item name or description.
4. Enter the quantity.
5. Choose a priority level.
6. Add specifications and a justification for the request.
7. Select a required-by date if applicable.
8. Click Submit Request.

After submission, the request is sent to the appropriate approval workflow. You can check the status from My Requests.

### B. Viewing your issued items

1. Open My Issued Items from the menu.
2. Review the item list assigned to you.
3. Use the item details page if you need more information.

### C. Adding an item to inventory

1. Go to Inventory > Add Item.
2. Enter the item name, quantity, condition, and location.
3. Add any relevant notes or specifications.
4. Click Save.

Inventory Officers can also review and update item information from the inventory list.

### D. Creating a transfer request

1. Go to Inventory > Transfers > New Transfer.
2. Select the source inventory and destination inventory.
3. Choose the items to be transferred.
4. Enter the reason and date, if required.
5. Submit the request.

The transfer will be tracked through approvals and can be reviewed later in the transfer list.

### E. Submitting a disposal request

1. Go to Inventory > Disposals > New Disposal.
2. Select the item to dispose.
3. Choose the reason for disposal.
4. Enter the condition assessment.
5. Add any supporting comments or attachments.
6. Submit the request.

The request will move through the approval process and can be monitored from the disposal list.

### F. Reviewing approvals

If your role requires approval rights:

1. Open the Pending Tasks or approval screen.
2. Review the request details.
3. Approve, reject, or return the request as needed.
4. Confirm that the action completed successfully.

## 6. Searching and filtering

Most list screens support:

- search boxes,
- filters by status,
- sorting, and
- page navigation.

Use these controls to quickly find records instead of scrolling through a long list.

## 7. Reports

Reports are available for users with the required permissions. Reports can help you:

- review inventory status,
- follow approvals,
- summarize item movement,
- audit requests and disposal activity.

## 8. Best practices

- Use clear item descriptions and complete justifications.
- Select the correct inventory location when creating requests.
- Check the status of requests regularly.
- Keep supporting details and attachments ready for transfers, repairs, or disposals.
- If you are unsure which role you should use, contact the system administrator.

## 9. Troubleshooting

If you have trouble using the system:

- confirm that you entered the correct email and password,
- make sure the application and backend API are running,
- refresh the page after a long idle period,
- use the Forgot Password option if you cannot remember your password,
- contact the administrator if a request or approval is stuck.

## 10. Support

For technical support or role-related questions, contact the system administrator or the inventory management team.
